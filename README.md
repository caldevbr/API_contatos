# API_contatos

API desenvolvida em PHP para gerenciamento de contatos de formulários web.
Funcionalidades

- Recebimento de dados via POST
- Validação de campos obrigatórios
- Validação de e-mail
- Validação de telefone
- Persistência em MySQL
- Envio de e-mail via SMTP utilizando PHPMailer
- Resposta em JSON
Tecnologias

- PHP
- MySQL
- PDO
- Composer
- PHPMailer
- SMTP
Estrutura
A API foi projetada para integração com sites institucionais e portfólios, permitindo armazenar contatos em banco de dados e enviar notificações por e-mail.
